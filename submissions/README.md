# Submissions

Each team's entry lives in its own folder here, named after the team:

```
submissions/<your-team-name>/
```

See [`CONTRIBUTING.md`](../CONTRIBUTING.md) for how to fork, branch and open a PR, and
[`SUBMISSION_TEMPLATE.md`](../SUBMISSION_TEMPLATE.md) for what your `SUBMISSION.md`
needs to cover. Don't edit anything outside your own folder.
